## 任务边界

为一个具名项目从已连接的 MCP 服务取得验收清单。清单提供核对项目，不代表它们已经完成。这个技能只读取服务返回的内容，无须编辑文件、执行终端命令或替用户签字。

## 流程

1. 从当前请求提取项目名，保留用户给出的大小写和空格。项目名未提供时请用户补充，避免把演示名称或工作区名称当成已确认的项目名。
2. 查看本轮可用工具，优先调用已连接的 mcp__demo__project_checklist，把项目名作为 project 参数传入。用户指定其他服务时，只有明确存在且提供同类能力的已连接工具才能用于该项目。调用一次并等待返回。
3. 读取服务返回的清单。如果服务有多个条目，保留原始顺序，将它们显示成可勾选的列表。只将项目名、数据来源和实际返回的条目写入结论。
4. 如果 MCP 返回错误或没有这个工具，显示服务名及可理解的错误原因。可以请用户重新选择 MCP 配置或检查服务是否启动。用户只要模板时可以在明确说明是草案后提供，不得将草案标成服务结果。
5. 如果结果很简短，直接展示它。没有检查证据时保持待检查状态，不能说测试通过、代码已修复或项目已经发布。

## 完成判据

回答交代项目名、MCP 调用结果与检查清单。服务失败时明确报告失败并给出下一步，不补造结果。
